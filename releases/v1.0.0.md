# Release v1.0.0 — network-safe branch

**Release date:** 2026-10-19
**Tag:** `v1.0.0`
**Status:** stable

This is the first source release of ACNX. It exists to fix a specific class of failure in the
earlier optimizer scripts from this family: after running them, Wi-Fi and Ethernet stopped
working and the NVIDIA overlay (Alt+Z) no longer opened.

Every build below has been audited byte by byte. No active line disables a networking service,
an NDIS component, a virtual Wi-Fi filter or an NVIDIA container.

## What was fixed

### One-Click — `ACNXClick.bat`

- 14 network services and 8 NDIS components restored.
- `BFE` → `auto`, `WinHttpAutoProxySvc` and `ClipSVC` → `demand`.
- `EnableActiveProbing` → `1`, `NoActiveProbe` → `0`.
- NVIDIA tray entry restored.
- `[1] Wifi Fixer` extended with `dot3svc`, `Eaphost`, `lltdsvc`, `wcncsvc`, `wlpasvc`.
- `[7] Nvidia Fixer` added.
- Six silent killers removed from the "Disable ALL Services" block: `dot3svc` (802.1X wired),
  `Eaphost` (WPA-Enterprise), `RmSvc` (radio control), `lltdsvc`, `wcncsvc`, `wlpasvc`.

### Platinum — `ACNXNUM+OPTIMIZER.cmd`

- `DisableOverlay` → `0`.
- `NETWORK + NVIDIA RESTORE` block inserted before the forced reboot.

### High Impact — `ACNXHI+OPTIMIZER.bat`

- Every NVIDIA container disable commented out.
- `NoDaemon` → `0`, `NvTray StartOnLogin` → `1` (×2).
- `NoActiveProbe` → `0`, `EnableActiveProbing` → `1` (×3).
- `WinHttpAutoProxySvc` `4` → `3`, `disabled` → `demand` (×2).
- `WlanSvc` → `auto` (×2), `BFE`/`Dnscache` → `auto`.
- `lmhosts` → `auto` (×4), `LanmanWorkstation` → `auto` (×2), `LanmanServer` → `demand` (×2).
- `RasMan`, `RemoteAccess`, `iphlpsvc` → `demand`.
- New `:acnx_fix` routine at `07 EXTRA` → `[5] NET+NVIDIA FIX`, including IPv6 and Teredo restore.

## Known side effects

Read before running. These are intentional optimizer changes.

| Effect | One-Click | Platinum | High Impact |
| --- | :---: | :---: | :---: |
| IPv6 disabled | yes | no | yes |
| UAC prompt disabled | yes | yes | yes |
| Windows Update disabled | no | yes (until 2099) | yes |
| `hypervisorlaunchtype off` (breaks WSL2/Hyper-V/Docker) | no | no | yes |
| `nx OptIn` (lower DEP coverage) | no | no | yes |
| Defender ATP service (`Sense`) disabled | yes | no | no |

Windows Firewall and the core Defender service are **not** touched by any build.
