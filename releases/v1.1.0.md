through [AME Wizard](https://github.com/Ameliorated-LLC/AME-Wizard) instead of a batch file.

verified those files you do not need to download them again.

## Playbook notes

Both `.apbx` files are 7z containers with **encrypted headers**. Opening one with 7-Zip produces:

```text
ERROR: Cannot open encrypted archive. Wrong password?
```

That is how AME Wizard playbooks are packaged — AME Wizard holds the key. The message is not
corruption and not a failed download. Verify with the SHA-256 above, then open the file with AME
Wizard.

| Playbook | What it applies |
| --- | --- |
| `ACNXPlaybook.apbx` | The ACNX service, network and GPU configuration |
| `ReimaginedOS-MOD.apbx` | ReimaginedOS layout and debloat, network and NVIDIA stack left intact |

## Requirements

- Windows 10 22H2 or Windows 11
- [AME Wizard](https://github.com/Ameliorated-LLC/AME-Wizard)
- Administrator
- ~1.5 GB free during install

## Install

```text
1. Run AME Wizard as administrator.
2. Drag the .apbx into the window.
3. Read the summary page, proceed.
4. Reboot.
```

## Do not stack

Playbooks and batch scripts apply overlapping service changes. Run one or the other. If you need
to switch, apply the matching fixer, reboot, then run the new one.

## Recovery

```powershell
Checkpoint-Computer -Description "Pre-ACNX-playbook" -RestorePointType MODIFY_SETTINGS
```

Afterwards, if Wi-Fi, Ethernet or the NVIDIA overlay breaks:

```text
ACNXClick.bat        ->  [1] Wifi Fixer   /   [7] Nvidia Fixer
ACNXHI+OPTIMIZER.bat ->  07 EXTRA -> [3] WIFI FIX / [5] NET+NVIDIA FIX
```

Reboot after. Full steps in [docs/TROUBLESHOOTING.md](../docs/TROUBLESHOOTING.md).
